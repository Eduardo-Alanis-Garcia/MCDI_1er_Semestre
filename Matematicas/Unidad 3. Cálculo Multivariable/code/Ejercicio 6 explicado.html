Ejercicio 6: minimización del costo del petróleo

Autor/a

Eduardo Alanís García

1 Introducción

Este documento desarrolla el Ejercicio 6, cuyo objetivo es encontrar el costo mínimo de enviar petróleo refinado a Japón a través del Estrecho de Malaca. Las decisiones que se optimizan son el tamaño del petrolero, \(t\), y la capacidad de la refinería, \(q\).

Se aplican dos métodos numéricos de optimización: Newton, que usa el gradiente y la matriz Hessiana de segundas derivadas, y BFGS, un método quasi-Newton que aproxima la inversa de la Hessiana. En ambos se incorpora una búsqueda lineal de Armijo para elegir pasos que reduzcan el costo y mantengan las variables dentro de su dominio válido.

2 1. Planteamiento del problema

La función c(t,q) representa dólares por kilolitro. El ejercicio restringe las variables a valores positivos, porque un tamaño de petrolero o una capacidad de refinería iguales o menores que cero no tienen sentido en este modelo:

\[ t>0,\qquad q>0. \]

Los parámetros que aparecen en el enunciado son:

Símbolo Valor Significado y unidades
\(a\) 0.20 Gastos fijos anuales
\(c_c\) 12.5 Precio del crudo, dólares por kL
\(c_i\) 0.50 Costo del seguro, dólares por kL
\(c_x\) 0.90 Costo de aduana, dólares por kL
\(i\) 0.10 Tipo de interés
\(n\) 2 Número de puertos
\(p\) 7000 Precio del terreno, dólares por m²
\(t\) Variable Tamaño del petrolero, kL
\(q\) Variable Capacidad de la refinería, barriles por día

La conversión de unidades indicada es \(1\text{ kL}=6.29\text{ bbl}\). Por ello, el tamaño del petrolero puede convertirse de kL a barriles multiplicando por 6.29; la capacidad de la refinería puede convertirse de barriles por día a kL por día dividiendo por 6.29.

2.1 1.1. Forma compacta del costo

Para simplificar la escritura se define

\[ S=nt+1.2q \]

y se agrupan los parámetros constantes en

\[ \begin{aligned} c_0 &= c_c+c_i+c_x, & A &= \frac{2.09\times10^4}{360}, & B &= \frac{1.064\times10^6}{52.47(360)},\\ C &= \frac{4.242\times10^4a}{52.47(360)}, & D &= \frac{1.813ip}{52.47(360)}, & E &= \frac{4.25\times10^3a}{52.47(360)},\\ F &= \frac{5.042\times10^3}{360}, && G = \frac{0.1049}{360}. \end{aligned} \]

Con los exponentes \(r=-0.3017\), \(s=0.4925\), \(u=0.7952\), \(v=0.861\), \(w=-0.1899\) y \(m=0.671\), la función se escribe como

\[ c(t,q)=c_0+At^r+B\frac{t^s}{q}+C\frac{t^u}{q} +D\frac{S^v}{q}+E\frac{S}{q}+Fq^w+Gq^m. \]

Esta expresión es la misma función del enunciado, pero con algunos factores agrupados para que sus derivadas y su implementación sean más manejables. Al minimizarla se busca un par \((t^*,q^*)\) con el menor costo posible dentro del modelo.

3 2. Condiciones de primer orden: el gradiente

El gradiente reúne las derivadas parciales de la función con respecto a cada variable. Una derivada parcial mide cómo cambia el costo cuando cambia una variable y se mantiene fija la otra. Un punto estacionario interior satisface

\[ \nabla c(t,q)= \begin{pmatrix}c_t(t,q)\\c_q(t,q)\end{pmatrix} = \begin{pmatrix}0\\0\end{pmatrix}. \]

Derivando

\[ \begin{aligned} c_t={}&Ar t^{r-1} +Bs\frac{t^{s-1}}{q} +Cu\frac{t^{u-1}}{q} +Dvn\frac{S^{v-1}}{q} +E\frac{n}{q},\\ c_q={}&-B\frac{t^s}{q^2} -C\frac{t^u}{q^2} +D\left(-\frac{S^v}{q^2}+1.2v\frac{S^{v-1}}{q}\right)\\ &+E\left(-\frac{S}{q^2}+\frac{1.2}{q}\right) +Fwq^{w-1}+Gmq^{m-1}. \end{aligned} \]

La primera derivada, \(c_t\), describe el cambio marginal del costo al variar el tamaño del petrolero; \(c_q\) describe el cambio marginal al variar la capacidad de la refinería.

4 3. La Hessiana

El método de Newton también usa las derivadas de segundo orden. La Hessiana organiza estas derivadas en una matriz:

\[ H_c(t,q)= \begin{pmatrix} c_{tt} & c_{tq}\\ c_{tq} & c_{qq} \end{pmatrix}. \]

En este modelo, las expresiones implementadas son

\[ \begin{aligned} c_{tt}={}&Ar(r-1)t^{r-2} +Bs(s-1)\frac{t^{s-2}}{q} +Cu(u-1)\frac{t^{u-2}}{q}\\ &+Dv(v-1)n^2\frac{S^{v-2}}{q},\\[3pt] c_{tq}={}&-Bs\frac{t^{s-1}}{q^2} -Cu\frac{t^{u-1}}{q^2}\\ &+Dvn\left(-\frac{S^{v-1}}{q^2} +1.2(v-1)\frac{S^{v-2}}{q}\right) -E\frac{n}{q^2},\\[3pt] c_{qq}={}&2B\frac{t^s}{q^3}+2C\frac{t^u}{q^3}\\ &+D\left(2\frac{S^v}{q^3}-2.4v\frac{S^{v-1}}{q^2} +1.44v(v-1)\frac{S^{v-2}}{q}\right)\\ &+E\left(2\frac{S}{q^3}-\frac{2.4}{q^2}\right) +Fw(w-1)q^{w-2}+Gm(m-1)q^{m-2}. \end{aligned} \]

5 4. Escalamiento de las variables

Los valores de \(t\) y \(q\) son del orden de cien mil, mientras que el costo es del orden de decenas. Para trabajar con coordenadas más pequeñas y equilibrar la escala de las variables, el código define

\[ \tau=\frac{t}{10^5},\qquad \kappa=\frac{q}{10^5}, \]

de modo que \(t=10^5\tau\) y \(q=10^5\kappa\). El vector de decisión escalado es \(z=(\tau,\kappa)^T\). Por ejemplo, el punto inicial \((\tau_0,\kappa_0)=(0.5,1)\) representa \(t_0=50\,000\) kL y \(q_0=100\,000\) bbl/día.

\[ \nabla_z\widetilde c= \begin{pmatrix}10^5&0\\0&10^5\end{pmatrix} \nabla_{(t,q)}c, \qquad H_{\widetilde c}= \begin{pmatrix}10^5&0\\0&10^5\end{pmatrix} H_c \begin{pmatrix}10^5&0\\0&10^5\end{pmatrix}. \]

6 5. Búsqueda lineal de Armijo

Un paso completo de Newton o BFGS puede ser demasiado grande, salir del dominio \(t,q>0\) o aumentar el costo. Para controlar el tamaño se usa una búsqueda lineal: se elige una dirección \(d\) y se prueba el nuevo punto

\[ z_{\text{nuevo}}=z+\alpha d, \]

donde \(\alpha\) es el tamaño del paso. La condición de Armijo exige una disminución suficiente:

\[ \widetilde c(z+\alpha d) \leq \widetilde c(z)+c_1\alpha\,\nabla\widetilde c(z)^Td. \]

El código empieza con \(\alpha=1\) y, si el punto no es válido o no reduce suficientemente el costo, multiplica \(\alpha\) por 0.5. Repite este retroceso hasta encontrar un paso aceptable o alcanzar el paso mínimo programado.

7 6. Método de Newton

En cada iteración, el paso de Newton resuelve el sistema lineal

\[ H_{\widetilde c}(z_k)d_k=-\nabla\widetilde c(z_k), \]

equivalente a \(d_k=-H_{\widetilde c}(z_k)^{-1}\nabla\widetilde c(z_k)\). Después de calcular la dirección, la búsqueda de Armijo decide cuánto avanzar.

Newton suele converger rápidamente cerca del óptimo, pero la Hessiana puede ser singular o producir una dirección que no reduzca el costo. El script cubre esos casos: si no puede resolver el sistema con una dirección finita de descenso, usa \(-\nabla\widetilde c\) (el descenso más pronunciado) como alternativa y aplica la misma búsqueda de Armijo. Si Armijo no encuentra ningún paso aceptable, informa un error en lugar de continuar silenciosamente.

8 7. Método quasi-Newton BFGS

BFGS significa Broyden–Fletcher–Goldfarb–Shanno. Es un método quasi-Newton porque aproxima la inversa de la Hessiana usando los cambios observados en las iteraciones, sin calcular una Hessiana nueva para determinar cada dirección.

La aproximación inicial de la inversa es la matriz identidad \(I\). En cada paso se calcula

\[ d_k=-H_k^{-1}\nabla\widetilde c(z_k), \]

y se aplica la búsqueda de Armijo. Después se definen

\[ s_k=z_{k+1}-z_k,\qquad y_k=\nabla\widetilde c(z_{k+1})-\nabla\widetilde c(z_k), \qquad \rho_k=\frac{1}{y_k^Ts_k}. \]

La actualización de la inversa aproximada es

\[ H_{k+1}^{-1} =(I-\rho_k s_k y_k^T)H_k^{-1}(I-\rho_k y_k s_k^T) +\rho_k s_k s_k^T. \]

El producto \(y_k^Ts_k\) debe tener curvatura positiva suficiente para que la actualización sea estable. El código comprueba esta condición; si no se cumple, reinicia la aproximación con la identidad. También reinicia y usa descenso por gradiente si la dirección BFGS no resulta finita o no apunta cuesta abajo.

9 9. Resultados e interpretación

La solución escrita del ejercicio reporta que ambos métodos partieron de \((\tau_0,\kappa_0)=(0.5,1)\) y convergieron al mismo mínimo numérico, con diferencias muy pequeñas por el método y el redondeo:

Método Iteraciones Tamaño del petrolero \(t^*\) (kL) Capacidad \(q^*\) (bbl/día) Costo ($/kL)
Newton 9 421 572.2112 204 504.6473 18.02506914
BFGS 15 421 572.2065 204 504.6467 18.02506914

El valor calculado para el gradiente escalado tiene norma menor que \(10^{-9}\) en ambos métodos, lo que satisface el criterio de parada empleado. La Hessiana escalada en la solución tiene valores propios aproximados de 0.0151 y 0.2429. Al ser ambos positivos, la Hessiana es positiva definida y el punto es un mínimo local estricto.

Esta conclusión describe el comportamiento de la función cerca del punto encontrado. La prueba local de curvatura positiva no basta por sí misma para asegurar que ningún otro punto admisible tenga menor costo.

9.1 9.1. Conversión de unidades del resultado

Con \(1\text{ kL}=6.29\text{ bbl}\), los valores reportados se pueden expresar también como

\[ t^*\approx421\,572.21(6.29) =2\,651\,689.21\text{ bbl}, \]

y

\[ q^*\approx\frac{204\,504.65}{6.29} =32\,512.66\text{ kL/día}. \]

Por lo tanto, el costo mínimo informado por el ejercicio es aproximadamente 18.0251 dólares por kL, con un petrolero de alrededor de 421 572.21 kL y una refinería de 204 504.65 bbl/día.

c_i = 0.50
c_x = 0.90
i_rate = 0.10

# Exponentes
r_exp = -0.3017
s_exp = 0.4925
u_exp = 0.7952
v_exp = 0.861
w_exp = -0.1899
m_exp = 0.671

# Coeficientes de la función compacta 
c0 = c_c + c_i + c_x
A = 2.09e4 / 360
B = 1.064e6 / (52.47 * 360)
C = 4.242e4 * a / (52.47 * 360)
D = 1.813 * i_rate * p_land / (52.47 * 360)
E = 4.25e3 * a / (52.47 * 360)
F = 5.042e3 / 360
G = 0.1049 / 360

# Escalas de las variables
scale_t = 1e5 # kL
scale_q = 1e5 # bbl/día

# Función de costo c(t,q), en dólares por kL.
oil_cost = function(t, q) {
  if (length(t) != 1L || length(q) != 1L ||
      !is.finite(t) || !is.finite(q) || t <= 0 || q <= 0) {
    return(Inf)
  }

  S = n_ports * t + 1.2 * q
  c0 +
    A * t^r_exp +
    B * t^s_exp / q +
    C * t^u_exp / q +
    D * S^v_exp / q +
    E * S / q +
    F * q^w_exp +
    G * q^m_exp
}

10.2 Gradiente y Hessiana analíticas

# Gradiente analítico respecto de (t,q).
oil_gradient = function(t, q) {
  S = n_ports * t + 1.2 * q

  c_t = A * r_exp * t^(r_exp - 1) +
    B * s_exp * t^(s_exp - 1) / q +
    C * u_exp * t^(u_exp - 1) / q +
    D * v_exp * n_ports * S^(v_exp - 1) / q +
    E * n_ports / q

  c_q = -B * t^s_exp / q^2 -
    C * t^u_exp / q^2 +
    D * (-S^v_exp / q^2 + 1.2 * v_exp * S^(v_exp - 1) / q) +
    E * (-S / q^2 + 1.2 / q) +
    F * w_exp * q^(w_exp - 1) +
    G * m_exp * q^(m_exp - 1)

  c(c_t = c_t, c_q = c_q)
}

# Hessiana analítica respecto de (t,q).
oil_hessian = function(t, q) {
  S = n_ports * t + 1.2 * q

  c_tt = A * r_exp * (r_exp - 1) * t^(r_exp - 2) +
    B * s_exp * (s_exp - 1) * t^(s_exp - 2) / q +
    C * u_exp * (u_exp - 1) * t^(u_exp - 2) / q +
    D * v_exp * (v_exp - 1) * n_ports^2 * S^(v_exp - 2) / q

  c_tq = -B * s_exp * t^(s_exp - 1) / q^2 -
    C * u_exp * t^(u_exp - 1) / q^2 +
    D * v_exp * n_ports *
      (-S^(v_exp - 1) / q^2 +
         1.2 * (v_exp - 1) * S^(v_exp - 2) / q) -
    E * n_ports / q^2

  c_qq = 2 * B * t^s_exp / q^3 +
    2 * C * t^u_exp / q^3 +
    D * (2 * S^v_exp / q^3 -
           2.4 * v_exp * S^(v_exp - 1) / q^2 +
           1.44 * v_exp * (v_exp - 1) * S^(v_exp - 2) / q) +
    E * (2 * S / q^3 - 2.4 / q^2) +
    F * w_exp * (w_exp - 1) * q^(w_exp - 2) +
    G * m_exp * (m_exp - 1) * q^(m_exp - 2)

  matrix(c(c_tt, c_tq, c_tq, c_qq), nrow = 2L, byrow = TRUE,
         dimnames = list(c("t", "q"), c("t", "q")))
}

10.3 Transformación a variables escaladas

# Transformaciones entre variables físicas (t,q) y escaladas (tau,kappa).

to_physical = function(z) {
  c(t = scale_t * z[1], q = scale_q * z[2])
}

scaled_cost = function(z) {
  physical = to_physical(z)
  oil_cost(physical["t"], physical["q"])
}

scaled_gradient = function(z) {
  physical = to_physical(z)
  c(scale_t, scale_q) *
    oil_gradient(physical["t"], physical["q"])
}

scaled_hessian = function(z) {
  physical = to_physical(z)
  scale_matrix = diag(c(scale_t, scale_q))
  scale_matrix %*%
    oil_hessian(physical["t"], physical["q"]) %*%
    scale_matrix
}

10.4 Búsqueda lineal de Armijo

# Búsqueda lineal de Armijo; descarta puntos fuera del dominio t,q > 0.
armijo_search = function(z, direction, gradient, value,
                          c1 = 1e-4, contraction = 0.5,
                          min_step = 2^-50) {
  slope = sum(gradient * direction)
  if (!is.finite(slope) || slope >= 0) {
    return(NULL)
  }

  step = 1
  while (step >= min_step) {
    candidate = z + step * direction
    if (all(is.finite(candidate)) && all(candidate > 0)) {
      candidate_value = scaled_cost(candidate)
      if (is.finite(candidate_value) &&
          candidate_value <= value + c1 * step * slope) {
        return(list(z = candidate, value = candidate_value, step = step))
      }
    }
    step = contraction * step
  }

  NULL
}

10.5 Método de Newton

newton_method = function(z0 = c(tau = 0.5, kappa = 1),
                          tolerance = 1e-9, max_iterations = 100L) {
  z = as.numeric(z0)

  for (iteration in 0:max_iterations) {
    value = scaled_cost(z)
    gradient = scaled_gradient(z)
    gradient_norm = sqrt(sum(gradient^2))

    if (gradient_norm < tolerance) {
      return(list(z = z, value = value, iterations = iteration,
                  gradient_norm = gradient_norm, converged = TRUE))
    }
    if (iteration == max_iterations) {
      break
    }

    hessian = scaled_hessian(z)
    newton_step = tryCatch(
      as.vector(solve(hessian, gradient)),
      error = function(e) rep(NA_real_, 2L)
    )
    direction = -newton_step

    # Si la Hessiana no produce descenso, usar -gradiente como respaldo.
    if (any(!is.finite(direction)) || sum(gradient * direction) >= 0) {
      direction = -gradient
    }

    search = armijo_search(z, direction, gradient, value)
    if (is.null(search)) {
      stop("Newton: la búsqueda de Armijo no encontró un paso aceptable.")
    }
    z = search$z
  }

  list(z = z, value = scaled_cost(z), iterations = max_iterations,
       gradient_norm = sqrt(sum(scaled_gradient(z)^2)), converged = FALSE)
}

10.6 Método quasi-Newton BFGS

bfgs_method = function(z0 = c(tau = 0.5, kappa = 1),
                        tolerance = 1e-9, max_iterations = 200L) {
  z = as.numeric(z0)
  inverse_hessian = diag(2L)

  for (iteration in 0:max_iterations) {
    value = scaled_cost(z)
    gradient = scaled_gradient(z)
    gradient_norm = sqrt(sum(gradient^2))

    if (gradient_norm < tolerance) {
      return(list(z = z, value = value, iterations = iteration,
                  gradient_norm = gradient_norm, converged = TRUE))
    }
    if (iteration == max_iterations) {
      break
    }

    direction = -as.vector(inverse_hessian %*% gradient)
    if (any(!is.finite(direction)) || sum(gradient * direction) >= 0) {
      inverse_hessian = diag(2L)
      direction = -gradient
    }

    search = armijo_search(z, direction, gradient, value)
    if (is.null(search)) {
      stop("BFGS: la búsqueda de Armijo no encontró un paso aceptable.")
    }

    z_next = search$z
    gradient_next = scaled_gradient(z_next)
    s = z_next - z
    y = gradient_next - gradient
    ys = sum(y * s)

    # Actualización BFGS de la Hessiana inversa aproximada.
    if (is.finite(ys) && ys > 1e-12 * sqrt(sum(s^2) * sum(y^2))) {
      rho = 1 / ys
      identity = diag(2L)
      left = identity - rho * tcrossprod(s, y)
      right = identity - rho * tcrossprod(y, s)
      inverse_hessian = left %*% inverse_hessian %*% right +
        rho * tcrossprod(s, s)
    } else {
      inverse_hessian = diag(2L)
    }

    z = z_next
  }

  list(z = z, value = scaled_cost(z), iterations = max_iterations,
       gradient_norm = sqrt(sum(scaled_gradient(z)^2)), converged = FALSE)
}

10.7 Reporte y ejecución de los métodos

report_result = function(method_name, result) {
  if (!result$converged) {
    warning(method_name, " no alcanzó la tolerancia solicitada.")
  }

  physical = to_physical(result$z)
  eigenvalues = eigen(scaled_hessian(result$z),
                       symmetric = TRUE, only.values = TRUE)$values

  cat("\n", method_name, "\n", sep = "")
  cat(sprintf("Iteraciones: %d\n", result$iterations))
  cat(sprintf("tau = %.10f, kappa = %.10f\n", result$z[1], result$z[2]))
  cat(sprintf("t* = %.4f kL (%.4f bbl)\n",
              physical["t"], physical["t"] * conversion_bbl_per_kL))
  cat(sprintf("q* = %.4f bbl/día (%.4f kL/día)\n",
              physical["q"], physical["q"] / conversion_bbl_per_kL))
  cat(sprintf("Costo = %.10f dólares/kL\n", result$value))
  cat(sprintf("Norma del gradiente escalado = %.3e\n",
              result$gradient_norm))
  cat("Valores propios de la Hessiana escalada:",
      paste(sprintf("%.8f", eigenvalues), collapse = ", "), "\n")
  if (all(eigenvalues > 0)) {
    cat("La Hessiana es positiva definida: mínimo local estricto.\n")
  }
}
